# Commands Cheatsheet

## Session commands

- `/help`: List all commands
- `/usage`: Provides remaining capacity
- `/clear`: Clears out the history and context
- `/cost`: How much current conversation has cost so far
- `/exit`: Ends session and exits claude
- `/export`: Generates a Markdown doc with all session info, prompts, responses, code changes, etc.
- `/rewind`: Undos the latest prompt and result, moving the context back to where it was before it.
